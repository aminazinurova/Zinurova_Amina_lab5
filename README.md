# Зинурова Амина, группа ЛА-2, Лабораторная работа №5

## 📌 Описание задания
Необходимо разработать консольное приложение с дружественным интерфейсом для работы с базой данных «Музей», состоящей из трех таблиц: «Экспонаты», «Посетители» и «Билеты». 
Программа должна уметь:
1. Читать данные из Excel-файла.
2. Просматривать базу данных.
3. Удалять элементы по ключу.
4. Добавлять новые элементы.
5. Выполнять 4 LINQ-запроса (2 на получение перечня, 2 на получение одного значения).
6. Сохранять изменения в Excel-файл.

---

## 🏗 Архитектура приложения
Приложение разделено на 6 файлов:
*   **Exhibit.cs** — класс для таблицы «Экспонаты».
*   **Visitor.cs** — класс для таблицы «Посетители» (адаптирован под колонку «Город проживания»).
*   **Ticket.cs** — класс для таблицы «Билеты».
*   **Checked.cs** — вспомогательный класс для валидации и проверки корректности пользовательского ввода.
*   **DatabaseManager.cs** — вспомогательный класс, содержащий всю логику (чтение, запись, добавление, удаление и LINQ-запросы).
*   **Program.cs** — консольный интерфейс с меню и проверкой ввода.

Для работы с Excel были использованы NuGet-пакеты: `ExcelDataReader` (для чтения) и `ClosedXML` (для записи).

## 🧠 Логика решения и алгоритмы

### 1. Классы данных
Каждый класс содержит приватные поля, свойства `{ get; set; }` для доступа к ним, конструктор и переопределенный метод `ToString()` для красивого вывода в консоль. В классе `Visitor` реализовано поле `City` (Город проживания), так как это указано в исходном файле варианта.

### 2. Чтение и запись Excel (`DatabaseManager.cs`)
*   **Чтение (`LoadData`):** С помощью `ExcelDataReader` файл загружается в `DataSet`. Далее циклом `foreach` мы проходим по строкам листов и создаем объекты классов, обращаясь к колонкам по индексу (`row[0]`, `row[1]`), что защищает программу от ошибок, если в заголовках Excel есть лишние пробелы. Цена очищается от буквы «р.» перед конвертацией в `decimal`.
*   **Сохранение (`SaveData`):** С помощью `ClosedXML` создается новая книга, листы заполняются данными из списков, и файл сохраняется под новым именем `_result.xlsx`, чтобы не повредить исходник.

### 3. Удаление и добавление
*   **Удаление:** При удалении экспоната по ID также удаляются все связанные с ним билеты (`Tickets.RemoveAll(...)`), чтобы не оставалось «битых» ссылок.
*   **Добавление:** Реализовано для всех трех таблиц. При добавлении билета программа проверяет через LINQ (`Any`), существует ли такой экспонат и посетитель, и только потом добавляет билет.

### 4. LINQ-запросы
1.  **Запрос 1 (1 таблица, одно значение):** Подсчет количества посетителей из введенного города.
2.  **Запрос 2 (2 таблицы, перечень):** Соединение таблиц «Билеты» и «Экспонаты» для вывода названия экспоната и цены билета.
3.  **Запрос 3 (3 таблицы, одно значение):** Двойной `join` таблиц для подсчета суммарной выручки по заданной эпохе за июнь 2023 года (метод `Sum()`).
4.  **Запрос 4 (3 таблицы, перечень):** Двойной `join` для вывода списка посетителей (с их городами), которые купили билеты на заданную эпоху.

## 🛡️ Обработка ошибок и проверка входных данных
Для защиты программы от некорректного пользовательского ввода реализован отдельный вспомогательный класс **`Checked`**:
1. **Проверка чисел (`ReadInt`, `ReadPositiveInt`):** все ID и возраст считываются через `int.TryParse` с проверкой на положительность (`x > 0`). При вводе текста или отрицательных чисел программа просит повторить ввод.
2. **Проверка строк (`ReadString`):** исключает ввод пустых значений или строк, состоящих только из пробелов (`string.IsNullOrWhiteSpace`).
3. **Проверка даты и стоимости (`ReadDate`, `ReadPositiveDecimal`):** при добавлении билета используются `DateTime.TryParse` и `decimal.TryParse` с проверкой `price >= 0`.
4. **Обработка файловых ошибок:** загрузка Excel-файла обернута в блок `try-catch`, что предотвращает аварийное завершение программы при отсутствии файла или отсутствии прав доступа.
5. **Оптимизация вывода:** использование `Take(10)` и `Take(20)` защищает консоль от переполнения тысячами строк.
